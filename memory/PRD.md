# ORA Developments PEI - Product Requirements Document

## Original Problem Statement
Build a complete, production-ready website for ORA Developments PEI (Operational Reality Advisors). A REAL business site for fleets, trades, and real operations to be connected to domain oradevelopmentspei.ca via Porkbun.

## User Personas
- **Fleet Operators**: Need tracking, compliance, and maintenance tools
- **Tradespeople**: Need field-to-office sync, job logging, time tracking
- **Blue-collar Workers in PEI**: Need practical apps for daily life (meal planning, expense tracking, resumes)

## Core Requirements (Static)
- Frontend-only React website
- 5 pages: Home, About, Solutions, Products, Contact
- Dark theme with ORA Blue (#1E3A8A) and ORA Orange (#F97316)
- Mobile-first responsive design
- Deployment-ready for Vercel with Porkbun domain instructions
